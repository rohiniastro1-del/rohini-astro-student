# Rohini Astro Student

Rohini Astro Student е настолна програма на български език за изчисляване и разглеждане на карти по ведическа астрология (джйотиш).

Програмата работи локално. Потребителският интерфейс се показва в самостоятелен настолен прозорец.

## Основни функции

- натална карта D-1 (Раши);
- дробни карти D-2, D-3, D-4, D-7, D-9, D-10, D-12 и D-24;
- северен и южен стил на картите;
- отделна транзитна карта и наслагване върху наталната карта;
- движение на транзитния момент по секунди, минути, часове, дни, седмици, месеци и години;
- преминаване към предишна или следваща смяна на лагна;
- Вимшоттари Даша и Чара Даша;
- Панчанга, Вара и Хора;
- отношения между планетите, Ащтакаварга, Нава Тара и Джаймини показатели;
- показатели за планетарна сила, изгаряне, ганданта, планетарна война и затъмнения;
- записване и отваряне на хороскопи;
- експорт на картите като PNG.

## Изчислителни настройки

- сидерален зодиак;
- Lahiri аянамша;
- цял знак като дом;
- геоцентрични позиции;
- избор между True Node и Mean Node за Раху и Кету;
- автоматична историческа часова зона или ръчно зададено отместване;
- настройваем орбис на изгаряне.

Астрономическите позиции се изчисляват чрез Swiss Ephemeris с резервен изчислителен режим при недостъпни файлове. Това е техническо описание на използваната изчислителна основа и не означава одобрение, партньорство или свързаност с външен проект или притежател на права.

## Изисквания

- Windows;
- Python 3.11 или съвместима версия;
- зависимостите, описани в `requirements.txt`.

## Инсталиране за разработка

```powershell
python -m pip install -r requirements.txt
```

## Стартиране

Настолен режим:

```powershell
./start_rohini_desktop.ps1
```

Режим за разработка:

```powershell
./start_dev.ps1
```

При директно стартиране на сървъра:

```powershell
python app.py
```

След това интерфейсът е достъпен локално на `http://127.0.0.1:5051`.
